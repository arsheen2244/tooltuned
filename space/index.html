ToolTuned: function calling with a 1.5B model

asheeee24/tooltuned-qwen2.5-1.5b is Qwen2.5-1.5B-Instruct fine-tuned with QLoRA to call tools. Given a request and a list of tools, it answers with <tool_call> blocks, or in plain text when no tool fits.

Run it yourself

  
The live version of this demo is a Gradio app in the repo's space/ folder. On a CPU it needs about 6 GB of free memory (3 GB with DEMO_DTYPE=bfloat16):

  
git clone https://github.com/arsheen2244/tooltuned
cd tooltuned/space
pip install -r requirements.txt
python app.py
